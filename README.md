# Reinforcement Learning: A First Look

A companion extra to *Supply Chain AI in Python*, written for [scmaiteaching.org](https://scmaiteaching.org). It is not part of the book.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23968091.svg)](https://doi.org/10.5281/zenodo.23968091) [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/charlesluo22/scm-ai-public/blob/main/RL_Introduction_for_Students.ipynb)

Reinforcement learning (RL) is learning to make a sequence of decisions by trial and error, guided only by a score (a reward), not by examples of the right answer.

The notebook, `RL_Introduction_for_Students.ipynb`, has two small experiments:

1. **Three slot machines:** the trade-off between trying something new and sticking with what looks best.
2. **A robot in a grid:** how a reward that comes at the end teaches the steps that lead to it.

Each experiment checks its own results.

## Running it

- **On Colab:** open the notebook with the button above, then choose *Runtime → Run all*. It needs nothing installed (Colab already has numpy and matplotlib), and the whole notebook takes under a minute: 49 seconds in a test run on 4 Nov 2026, almost all of it in the slot-machine experiment. Its first cell has step-by-step help for a first time in Colab.
- **On your own machine:** Python 3 with numpy and matplotlib, in Jupyter.
